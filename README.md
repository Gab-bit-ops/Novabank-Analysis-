# NovaTrust Bank Performance Analysis
## Project Overview
A complete end-to-end banking data analysis project focused on uncovering customer, transaction, revenue, profitability, and product performance insights to support data-driven business decisions.

## 🔄 Project Workflow
1. Data Cleaning — Power Query
I started by using Power Query to prepare the raw banking dataset for analysis. This involved:
Cleaning and transforming the raw data
Handling inconsistencies and formatting issues
Checking data types and data quality
Preparing the datasets for SQL analysis
2. Exploratory Data Analysis — MySQL
I then used MySQL to perform Exploratory Data Analysis (EDA) and answer key business questions, including:
Which branch generates the highest revenue?
Which customer segment contributes the most revenue?
Which banking product records the highest transaction volume?
Is monthly revenue growing, stable, or declining?
How do fee waivers affect profitability?
I used SQL techniques including aggregation, filtering, grouping, sorting, and JOINs to derive the insights.
3. SQL Verification
After obtaining the results, I performed SQL verification checks to validate the accuracy and consistency of the findings before moving to visualization.
4. Data Visualization — Power BI
Finally, I used Power BI to transform the analysis into an interactive dashboard.
The dashboard highlights:
Total Customers
Revenue
Transaction Success Rate
Average Customer Satisfaction
Monthly Revenue Trend
Revenue by Customer Segment
Revenue by Product
Profit by Transaction Type
Revenue by Branch
## 🛠️ Tools Used
Power Query — Data Cleaning & Transformation
MySQL — EDA & Business Analysis
Power BI — Data Visualization & Dashboarding
SQL — Data Querying & Validation
